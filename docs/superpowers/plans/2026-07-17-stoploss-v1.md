# Stoploss v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a numerical Stoploss + reserved admit path driven by logic Evidence so we can observe and tweak live behavior.

**Architecture:** `Evidence` projects Thesis logic onto one symbol. `Stoploss` owns `lockedFloor` / `trailDistance` / `weight` and emits hold|stop|take_profit. Desk composes one Stoploss per Position; Crypto calls `Regulate` each tick after Decide. Decide keeps enter + liquidity reduce; full exits move to Stoploss.

**Tech Stack:** Go, existing strategy/broker/trader packages, standard testing.
